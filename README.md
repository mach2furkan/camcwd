# Educational Financial Dashboard Simulation

![Dashboard Demo](https://via.placeholder.com/800x400?text=Interactive+Market+Simulation+Dashboard)

**Academic Disclaimer**: This project is a purely educational simulation developed for practicing web development skills. All market data is artificially generated and should not be used for financial decisions.

## 📌 Project Overview
A responsive financial dashboard simulating real-time market data visualization with interactive 3D elements, created to demonstrate:

- Modern React development patterns
- Data visualization best practices
- Animation performance techniques
- Simulated financial modeling

## 🛠 Technical Implementation

### Core Technologies
| Component | Technology Stack | Educational Value |
|-----------|------------------|-------------------|
| Frontend | React 18, TypeScript 5 | Type-safe component development |
| Animations | Framer Motion 10 | Physics-based motion principles |
| Charts | Recharts 2.8 | Financial data visualization |
| Styling | Tailwind CSS 3 | Utility-first CSS workflow |
| Build | Vite 5 | Modern frontend tooling |

### Key Features
```typescript
// Sample simulation engine (educational purposes only)
const simulateMarketMovement = (basePrice: number): number => {
  // Uses geometric Brownian motion principles
  const volatility = 0.05;
  const drift = 0.01;
  return basePrice * (1 + drift + volatility * (Math.random() - 0.5));
}
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/mach2furkan/camcwd.git
   cd camcwd
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```
